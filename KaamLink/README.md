# KaamLink

## Find the Right Worker. Get the Job Done.

KaamLink is a skilled-worker marketplace application concept.

The goal is to connect customers with trusted and verified skilled workers near their location.

---

# Project Status

Version: 1.0.0

Current stage:

Frontend Foundation

This version is a working frontend prototype.

Backend services will be connected in later stages.

---

# Main Users

KaamLink will have two primary user types:

## 1. Customer

A customer can:

- Create an account
- Search for services
- Find nearby workers
- View worker profiles
- Check ratings
- Check reviews
- Check experience
- Chat with workers
- Call workers
- Request workers
- Book jobs
- Make payments
- Review workers
- Report problems

---

## 2. Worker

A worker can:

- Create a professional account
- Add profile photo
- Add name
- Add contact information
- Verify email / phone
- Verify identity where required
- Add skills
- Add experience
- Add qualifications
- Add services
- Add service charges
- Set availability
- Receive job requests
- Accept or decline jobs
- Chat with customers
- Call customers
- Complete jobs
- Receive payments
- Receive ratings
- Build professional reputation
